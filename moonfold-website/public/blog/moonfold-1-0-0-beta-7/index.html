Moonfold 1.0.0-beta.7: safer Windows upgrades, settings that stay put, Stable or Beta

Beta 7 fixes Windows upgrades that left Moonfold missing, stops seven settings pages from crashing, and lets you choose Stable or Beta updates.

Written by
The Moonfold team
Published
Nov 13, 2026
Reading time
1 min

In this post

  • Windows upgrades no longer leave Moonfold missing
  • Settings pages no longer crash
  • Stable or Beta

Beta 7 is a fix release with one new setting. Beta 6 updates to it by itself, and there are no database changes.

Windows upgrades no longer leave Moonfold missing

If a Moonfold helper was still running in the background, an upgrade could remove the app and then fail to write the new one. Windows then said it was "searching for Moonfold (Beta).exe". The installer now closes every process running from the install folder first. If this happened to you, run the beta 7 installer over it; your projects, threads and settings are kept. The full story is in Windows is searching for an .exe after an update.

Settings pages no longer crash

Memories, Mobile app, Plugins, Handoff, Computer use, Personalization and Prompt profiles opened full-window and failed with "Something went wrong". They now open in the settings panel like every other page.

Stable or Beta

Settings → About → Update track chooses between Stable releases and Beta builds, which get new features first. Switching installs the newest build of that track in place and keeps your data. There is no Stable release yet, so for now everyone is on Beta, and choosing Stable tells you so. See Switch between Stable and Beta.

Try Moonfold. It is free, open source and runs the agents you already use, with your own logins.
