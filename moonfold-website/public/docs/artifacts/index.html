Artifacts

Everything a thread produced or was given is listed under Artifacts in the thread details panel: each file its agent changed, newest first, and each file attached to its messages. Choose one to open it in the file preview. A file whose last change deleted it stays in the list but can't be opened.

The file preview shows images, video, audio, PDF and HTML pages, Markdown, CSV and TSV tables, and also Word documents (.docx) and Excel workbooks (.xlsx):

  • A Word document shows its text, headings, lists, tables, links and embedded pictures. Pictures stored on the web are not loaded, and links open in your browser.
  • A workbook shows each sheet as a table, up to 500 rows and 50 columns per sheet, with dates written as dates. Formatting, charts and merged cells are not shown.

The preview reads the file in your browser; nothing is converted or uploaded.
