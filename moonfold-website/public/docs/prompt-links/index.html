Prompt links

A prompt link opens Moonfold with a prompt ready to send. Use one to share a prompt on social media, or to put a one-click fix in a pull request comment.

A link never runs anything. It opens a draft. You read the prompt, then press Send. A link cannot change your permission mode, branch, or worktree. Your own defaults apply.

Make a link

Open the command palette and choose Copy prompt link. It copies the draft in the composer. When the project is on GitHub, Copy prompt link with repo and model also adds the repository and the model you picked. Sent messages have a Copy prompt link button too.

You can also write a link by hand. The desktop app opens moonfold:// links directly:

moonfold://new?prompt=Rate%20my%20code
moonfold://new?prompt=Fix%20the%20build&repo=owner/name&provider=codex&model=gpt-5.5
moonfold://new?pr=owner/name/123&prompt=Fix%20the%20failing%20check

A Moonfold build that is configured with a hosted web app copies https://<hosted-app>/new?… links with the same parameters instead.

ParameterMeaning
promptThe prompt. Required, except on pull request links. At most 8,000 characters.
repoA GitHub repository, as owner/name or its URL.
providerA provider such as codex or claude.
modelA model of that provider, by its id or name.
prA GitHub pull request, as owner/name/123 or its URL.

Encode the prompt for a URL. In JavaScript, use encodeURIComponent.

Open a link

A moonfold:// link opens in the desktop app. On a hosted web app, the link first asks where to open it: the desktop app, this browser when it is connected to a machine, or the download page. Select Remember my choice to skip this step next time.

  • No repo: the draft opens without a project, on the machine you used last.
  • repo: the draft opens in your most recently used project for that repository. A fork counts only for its own owner. When you do not have the repository, choose Clone or Use without project.
  • provider and model: used when you have that provider set up. Otherwise your default model is used, and Moonfold tells you.
  • pr: opens the thread linked to that pull request on any connected machine, with the prompt in its composer. When no thread is linked, the draft goes on the pull request branch in a new worktree. Moonfold checks the code out only after you confirm, because the checkout runs your setup script on it.

A thread link with a prompt, such as moonfold://threads/<environment>/<thread>?prompt=…, puts the prompt in that thread's composer. If you already typed a draft there, Moonfold asks before it replaces it.

Moonfold removes characters you cannot see, such as zero-width and hidden tag characters, because they can hide instructions for the agent. When a prompt had them, Moonfold warns you that it may be malicious.

Share a thread

Copy thread copies a link such as <moonfold-thread://v2/<environment>/<thread>>. Paste it anywhere, such as Slack, a GitHub comment, or your notes. On a phone with Moonfold installed, it opens the thread in the app. Elsewhere, opening it asks where to open it, like a prompt link, then opens the thread. Only someone connected to the machine that runs the thread can see it. In Moonfold, a thread link in a message opens the thread in the app.
