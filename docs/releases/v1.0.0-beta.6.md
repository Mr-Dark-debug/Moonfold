Moonfold beta 6 brings everything from the 1.0 release candidate to the beta line, so beta 5 updates
to it by itself: a crew that keeps working on your project, a phone that reaches your computer on
any network, pull requests that fix their own failing checks, and a mark that shows what Moonfold is
doing. Moonfold is an open-source desktop and web workspace for coding agents, built on
[T3 Code](https://github.com/pingdotgg/t3code). It is not affiliated with or endorsed by OpenAI,
Anthropic, Google, DeepSeek, Cursor or any other provider; it runs their CLIs with your own logins.

> [!WARNING]
> This is a beta. The desktop installers are **not signed**: macOS and Windows will warn before the
> first launch. [Install and first run](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/install.md)
> explains how to open them. Orbit runs agents without asking you; start it at the Propose level
> and read what it does before you give it more.

## What's new

- **Orbit.** A crew of agents that keeps working on one project while you are away. The scout
  reads what people say on GitHub, Hacker News, subreddits and feeds; the planner ranks a backlog;
  the builder builds the top item and opens a pull request; the sentinel checks security every
  day; the herald drafts release notes and announcements. You write the mission, choose how far
  the crew may go on its own, and cap its runs per day. Open **Orbit** in the sidebar.
  [Guide](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/orbit.md).
- **Reach from anywhere.** The Android app reaches your computer on mobile data or any other
  network, with no account. Moonfold's relay passes the connection along; it stays encrypted end to
  end to your computer, so the relay never sees what you do. Turn it on in
  **Settings → Mobile App** and scan a new code. You can also run your own relay.
  [Guide](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/mobile-app.md#reaching-your-computer).
- **Fix failing checks.** A pull request you create from a thread is watched for you. When a
  check fails, the agent reads the failure and pushes a fix, up to three tries, never by weakening
  a test. Change the number in **Settings → Source Control**.
  [Guide](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/source-control.md#fix-failing-checks).
- **Agents learn from your corrections.** When you correct how an agent works in a project, it
  can note that for next time. The note waits as a suggestion in **Settings → Memories** until you
  accept it. Memories also have a kind for setup facts, such as how the tests run, and now reach
  Cursor, OpenCode, Muse Code and agents connected through ACP.
  [Guide](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/memories.md).
- **The living mark.** Moonfold's mark now shows what is happening: the star travels the ring
  while an agent works, the moon breathes while it waits for you, and the ring levels when
  something needs attention. Each state has a still form when you prefer reduced motion.
- **The Android app updates itself.** Moonfold for Android 0.3.0-beta.1, attached below, checks
  for new versions once a day and installs them after you agree. Long-press its icon for
  **Check for updates**. Install 0.3 by hand once; after that it updates itself.
  [Guide](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/mobile-app.md#updates).

## Changed

- `moonfold relay` runs an Anywhere relay on any machine with Node.
- Brand kits record each review round in `reviews/index.md`, with every reviewer kept on one seat.
- If you installed 1.0.0-rc.1, install this build by hand: that version only looks for other
  release candidates, and there will be none.

## Upgrading

Beta 5 updates to this build by itself. Two database migrations run on first start. Nothing else
changes until you turn a feature on.

## Not verified yet

These run agents, so they need a provider sign-in this build was not tested with: a full Orbit
crew run, the CI fixer on a real failing check, and a correction saved as a suggestion.
