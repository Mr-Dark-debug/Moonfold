Beta 7 fixes Windows upgrades that left Moonfold missing, settings pages that crashed, and lets you
choose between Stable and Beta updates. Moonfold is an open-source desktop and web workspace for
coding agents, built on [T3 Code](https://github.com/pingdotgg/t3code). It is not affiliated with or
endorsed by OpenAI, Anthropic, Google, DeepSeek, Cursor or any other provider; it runs their CLIs
with your own logins.

> [!WARNING]
> This is a beta. The desktop installers are **not signed**: macOS and Windows will warn before the
> first launch. [Install and first run](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/install.md)
> explains how to open them.

## Fixed

- **Windows: upgrading no longer leaves Moonfold missing.** When a Moonfold helper was still
  running in the background, an upgrade could remove the app and fail to put the new one in place,
  so Windows said it was "searching for Moonfold (Beta).exe". The installer now closes every
  Moonfold process first. If this happened to you, run this installer; your projects, threads and
  settings are kept.
- **Settings pages no longer crash.** Memories, Mobile app, Plugins, Handoff, Computer use,
  Personalization and Prompt profiles opened full-window and failed with "Something went wrong".
  They now open in the settings panel like every other page.

## New

- **Stable or Beta.** **Settings → About → Update track** chooses between Stable releases and
  Beta builds, which get new features first. Switching installs the newest build of that track in
  place and keeps your data. There is no Stable release yet, so for now everyone is on Beta.
  [Guide](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/updating.md#switch-between-stable-and-beta).

## Upgrading

Beta 6 updates to this build by itself. No database changes.
