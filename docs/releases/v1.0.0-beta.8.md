Beta 8 brings in conversations you had with other agents. Paste a session ID from Claude Code,
Codex, Antigravity or Pi, or pick one from a list, and Moonfold turns it into a thread you can keep
working in. Moonfold is an open-source desktop and web workspace for coding agents, built on
[T3 Code](https://github.com/pingdotgg/t3code). It is not affiliated with or endorsed by OpenAI,
Anthropic, Google, DeepSeek, Cursor or any other provider; it runs their CLIs with your own logins.

> [!WARNING]
> This is a beta. The desktop installers are **not signed**: macOS and Windows will warn before the
> first launch. [Install and first run](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/install.md)
> explains how to open them.

## See it working

**Import a chat from another agent.** A Claude Code session found by its ID and imported with its
messages and tool calls.

## New

- **Import chat sessions.** Open **Import chat session** from the download button at the top of the
  sidebar, a project's menu or the command palette. Paste a session ID and select **Find**, or pick
  a recent session from the list. The thread keeps the messages, the thinking and the tool calls,
  and you can continue it with any provider. Works with Claude Code, Codex, Antigravity and Pi
  sessions on the computer running Moonfold. Moonfold only reads the original; it never changes it.
  [Guide](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/import-sessions.md).

## Upgrading

Beta 7 updates to this build by itself. No database changes.
