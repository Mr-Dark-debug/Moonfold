The fourth Moonfold beta brings Moonfold to your phone. Moonfold is an open-source desktop and web
workspace for coding agents, built on [T3 Code](https://github.com/pingdotgg/t3code). It is not
affiliated with or endorsed by OpenAI, Anthropic, Google, DeepSeek, Cursor or any other provider; it
runs their CLIs with your own logins.

> [!WARNING]
> This is a beta. The desktop installers are **not signed**: macOS and Windows will warn before the
> first launch. [Install and first run](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/install.md)
> explains how to open them. Back up anything important before letting an agent change it.

## What's new

- **Moonfold for Android, beta 1.** Follow and drive your computer from your phone. There is no
  account: turn it on in Settings → Mobile App, scan the code once, and the phone stays paired.
  Close and reopen the app as often as you like; while Moonfold runs on your computer, it connects
  by itself. Install `Moonfold-Android-0.1.0-beta.1.apk` from this release.
  [Guide](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/mobile-app.md).
- **An encrypted connection with nothing in between.** The phone trusts only the computer in the
  code it scanned, with no service, domain or certificate authority involved. Paired phones are
  listed in Settings → Connections, and you can revoke one there.
- **Content exclusions.** List paths agents must leave alone, per project, in Settings → Prompt
  Profiles → Agent limits. Claude Code's file tools are blocked from them. Other agents get them as
  an instruction, and shell commands can still reach them, so keep real secrets out of the project.
- **A token limit for one run.** Stop a runaway task once a run has added a set number of tokens.
  Each message starts with a fresh allowance. It works with agents that report usage during a turn:
  Codex and Claude.

## Fixed

- The dark theme rendered saturated blue on older Chromium browsers and Android web views.

## Good to know

- The phone needs a network it shares with your computer: the same Wi-Fi, or Tailscale or a VPN
  when you are away. Moonfold runs no relay. If your computer asks whether Moonfold may accept
  network connections, allow it for private networks.
- Android only for now, installed from the APK. There is no iPhone app yet.
- Android may warn about installing from your browser or file manager the first time.
- Upgrading from beta 1 or 2 needs one manual install; beta 3 and later update themselves.

Everything else from beta 3 carries over: multi-provider handoff, prompt profiles, scheduled
messages, DeepSeek Harness and local models. Full list in
[CHANGELOG.md](https://github.com/Mr-Dark-debug/Moonfold/blob/main/CHANGELOG.md).
