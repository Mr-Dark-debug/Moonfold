The fifth Moonfold beta gives the new thread screen a background of your choice, adds brand kits, and
brings in six weeks of upstream work, including a redesigned interface. Moonfold is an open-source
desktop and web workspace for coding agents, built on [T3 Code](https://github.com/pingdotgg/t3code).
It is not affiliated with or endorsed by OpenAI, Anthropic, Google, DeepSeek, Cursor or any other
provider; it runs their CLIs with your own logins.

> [!WARNING]
> This is a beta. The desktop installers are **not signed**: macOS and Windows will warn before the
> first launch. [Install and first run](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/install.md)
> explains how to open them. Back up anything important before letting an agent change it.

## What's new

- **Home screen backgrounds.** The new thread screen can show artwork behind the prompt. Open
  Settings → Appearance → Home screen, choose Moonfold, Golden hour or Purple wind, and pick how it
  is drawn: as ASCII text that follows your theme, or as an image. **Classic (no image)** is the
  default, so the screen looks the same until you choose one. Your choice is saved per device.
  [Guide](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/appearance.md#home-screen-background).
- **Cassandre, brand kits.** Start a message with `/brand` and describe what you are building. The
  agent asks about the brief, explores two to five directions, shows each one as a picture, and saves
  the kit in your project: name, logos, colors for light and dark, type, voice, exports for CSS,
  Tailwind, SCSS, TypeScript and JSON, and a brand book page. Nothing in your code changes unless you
  say yes. [Guide](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/user/brand-kits.md).
- **Question cards.** Agents with Moonfold's tools can stop and ask you in the thread, with
  pictures on the options, and continue when you answer.
- **A redesigned interface.** Moonfold merged upstream T3 Code's design overhaul, and the new look
  is now the only design. The composer is simpler, with grouped controls and one control for the
  model and its effort. You choose what the thread details card on the right shows. Settings and
  Usage open as large panels over your thread. F6 moves between areas of the workspace, and the
  sidebar works from the keyboard.
- **Review and files.** Review local commits in the Diff pane, open a tool call's diff in it, and
  mark pull request files as viewed with shift-click. Pull request comments appear in the chat. The
  file viewer previews Office files, OpenDocument, EPUB, notebooks, archives, SQLite databases,
  fonts and Mermaid diagrams, and the file explorer can be resized.
- **Agents.** You can see and stop the dev servers a thread started. Agents ask you for a secret
  with a private card instead of in chat, and can link to another environment (a Labs beta).

## Changed

- About 4,000 upstream commits merged in, with their fixes and performance work. What Moonfold kept
  or left out, and why, is in
  [docs/DECISIONS.md](https://github.com/Mr-Dark-debug/Moonfold/blob/main/docs/DECISIONS.md) (D-62
  to D-64). The hosted relay and account pages stay off, because Moonfold has no hosted service.

## Good to know

- Beta 3 and later update themselves. If you use Moonfold for real work, copy `~/.moonfold` before
  you update.
- `/brand` and question cards are covered by automated tests. They have not yet been run against a
  live provider, because the maintainer's Codex is limited until 19 November and Claude Code is not
  signed in on the build machine. Tell us what you find.
- No new Android build. Moonfold for Android beta 1 is unchanged and has not been re-tested against
  this release's server.
- Installers are unsigned, as before.

Everything else from beta 4 carries over: multi-provider handoff, the mobile pairing listener,
content exclusions, the token limit, prompt profiles, scheduled messages and local models for Pi.
Full list in
[CHANGELOG.md](https://github.com/Mr-Dark-debug/Moonfold/blob/main/CHANGELOG.md).
